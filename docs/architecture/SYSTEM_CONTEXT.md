# 系统上下文

## 系统概述

灵犀服务台是一个 AI 原生的内部服务管理 SaaS，采用多租户架构，以工作空间（Workspace）为租户隔离单元。

## 核心领域

### 1. 工作空间域（Workspace Domain）
- 工作空间管理
- 用户与成员
- 角色与权限
- 团队管理
- 邀请机制
- 租户隔离

### 2. 工单域（Ticket Domain）
- 请求接入
- 工单生命周期
- 消息与评论
- SLA 管理

### 3. 知识域（Knowledge Domain）
- 知识源
- 文档管理
- 向量检索
- 知识反馈

### 4. AI 域（AI Domain）
- 模型网关
- 分类与摘要
- RAG 检索
- 工具调用
- 策略引擎

### 5. 自动化域（Automation Domain）
- 规则引擎
- 连接器
- 审批流程

### 6. 商业化域（Billing Domain）
- 套餐管理
- 订阅管理
- 用量计量
- 支付订单

## 外部依赖

- 飞书开放平台
- 邮件服务（SMTP/IMAP）
- 大模型 API 服务
- 对象存储服务
- 支付网关

## 非功能性约束

- 多租户隔离：所有业务表包含 workspace_id
- 审计：所有写操作进入审计日志
- 安全：TLS、密码强哈希、密钥加密存储
- 性能：普通 API P95 < 500ms
