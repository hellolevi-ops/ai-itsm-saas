## 3. 已完成的关键决策

### 3.1 产品策略
- **目标客户**：中国 50—500 人成长型企业，2—15 人 IT 支持团队
- **产品定位**：AI 原生内部服务管理 SaaS，首阶段聚焦 IT 支持
- **核心价值**：把企业群聊和邮箱，十分钟升级成 AI 服务台
- **商业模式**：免费工作区 + 按工作区分层订阅 + AI 用量包

### 3.2 技术架构
- **架构风格**：模块化单体，不使用微服务
- **多租户隔离**：workspace_id 贯穿所有业务表 + PostgreSQL RLS
- **AI 策略**：统一模型网关，多家国产模型 API（阿里云百炼/腾讯混元/百度文心）
- **向量检索**：MVP 使用 PostgreSQL pgvector，后续可扩展

### 3.3 技术栈
- **前端**：Next.js / React / TypeScript
- **后端**：NestJS（TypeScript）
- **数据库**：PostgreSQL + pgvector
- **缓存/队列**：Redis + BullMQ
- **对象存储**：阿里云 OSS / 腾讯云 COS
- **部署**：阿里云 ECS / 容器服务

### 3.4 MVP 范围
- **入口**：Web 门户、邮件接入、飞书机器人（优先）
- **核心功能**：工作区、工单、AI 分类/摘要/回复、知识 RAG、SLA、商业化基础
- **合规**：审计日志、数据导出/删除、多租户隔离
