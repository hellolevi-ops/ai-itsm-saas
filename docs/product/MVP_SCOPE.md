# MVP 范围定义

## MVP 核心目标

验证 "AI 服务收件箱" — 让成长型企业在 10 分钟内启用，从飞书/邮箱/Web 直接接收请求，AI 自动完成分流、答复、知识沉淀。

## MVP 功能范围

### P0 必须包含

1. 工作区与成员
   - 工作区创建、邀请、基础权限（Requester / Agent / Admin / Owner
   - 自助注册（邮箱）

2. 渠道接入
   - Web 门户
   - 邮件接入
   - 飞书机器人/应用

3. 工单核心
   - 统一收件箱
   - 工单生命周期（状态机）
   - AI 分类、摘要、字段补齐、优先级与分派建议

4. 知识库
   - 文档导入
   - 知识管理
   - 引用式问答

5. AI 辅助坐席
   - 回复草稿
   - 相似工单推荐
   - 知识草稿生成

6. 服务管理 Lite
   - 基础服务项
   - 基础 SLA
   - 基础自动化规则

7. 分析与报表
   - 基础报表
   - 满意度
   - 审计日志

8. 商业化
   - 套餐、配额
   - 订阅和用量管理

9. 数据管理
   - 数据导出
   - 删除和保留策略

## MVP 明确不包含

- 完整 CMDB 和自动发现
- 监控、日志和 APM
- 远程控制、补丁和终端管理
- 通用 BPM/低代码平台
- 复杂项目管理
- 自研基础模型
- 大规模呼叫中心和电话系统
- 企业微信/钉钉（P1）
- OIDC/SAML SSO（P1）
- 多团队与值班规则（P1）
- API、Webhook 和通用连接器（P1）
- 轻量资产上下文（P1）
- 审批节点和受控动作（P1）
- 多部门 ESM（P2）

## 技术约束

- 模块化单体架构，不上微服务
- PostgreSQL + 显式 workspace_id 隔离
- 所有写操作有审计记录
- AI 模型通过统一适配层调用
- 事务 Outbox 保证业务事件可靠投递
