# Release Notes Draft

Version: M10 internal beta readiness

## Available In Beta

- Workspace registration and login
- Workspace creation and role-based membership
- Ticket submission, queue, detail, replies and status progression
- AI-assisted ticket suggestions with human review
- Knowledge draft and publish workflow
- Service catalog Lite and request templates
- WeCom mock inbound channel
- Workspace invitation links
- Billing plan catalog and manual order activation
- Health probes and baseline security headers
- Draft compliance center
- Beta feature flags and feedback intake

## Not Yet Production Ready

- Real WeCom production callback cryptography and outbound replies
- Real payment provider, invoice, tax and refund workflows
- Final compliance/legal approval
- CI/CD, rollback rehearsal and backup/restore drill
- Load testing and capacity planning
- Production monitoring and alerting

## Known Boundaries

The current beta is intended to prove workflow value and implementation stability. It must not be marketed or operated as a production service.
