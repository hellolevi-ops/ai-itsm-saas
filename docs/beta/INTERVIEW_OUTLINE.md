# Design Partner Interview Outline

## Context

- Team size and service desk workload
- Current intake channels
- Current escalation and SLA process
- Existing tools and pain points

## Workflow Test

- Ask the partner to submit a real but non-sensitive request.
- Observe whether the ticket category, template and status language make sense.
- Ask an agent to review the AI suggestion.
- Ask whether the knowledge article would reduce repeat work.

## Value

- Which step saved time?
- Which step felt risky?
- Which feature is required before weekly use?
- What would make this worth paying for?

## Risk

- Data sensitivity
- Compliance concerns
- Required audit evidence
- Channel integration requirements

## Payment Validation

Payment validation is a manual interview activity. Do not connect or charge through a real payment provider during M10.
